欢迎来到 DBlog！这是一个纯静态、无需数据库的个人站点，支持：

  • 文章（Markdown 编写）
  • 微博（按年份归档，一个文件写一年）
  • 多主题切换
  • 全文检索
  • 手机 / 电脑自适应

#快速开始

  1. 在 content/posts/ 里添加 .md 文件即可发布新文章。
  2. 在 content/weibo/2026.md 里用 ## 日期 写微博。
  3. 运行 npm run build 生成站点，npm run dev 本地预览。

#示例代码

function hello(name) {
  return `Hello, ${name}!`;
}

console.log(hello('博客'));
